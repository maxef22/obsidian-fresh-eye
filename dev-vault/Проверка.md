# Проверка плагина

Старый старик рассказал рассказ про то, как он буквально каждый вечер буквально сидел у моря и слушал, как морем пахнет ветер.

Квадрат арены, квадрат палаток, квадрат дорожки — всё это ему снилось.

Этот блок кода проверяться не должен, хотя в нём тоже есть повторы:

```js
const квадрат = 1; // квадрат квадрат квадрат
```

И эта [[ссылка]] тоже не должна ничего ловить.

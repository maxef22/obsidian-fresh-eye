# Свежий взгляд для Obsidian

Плагин для Obsidian, который находит в тексте **похожие по звучанию и написанию слова, стоящие слишком близко друг к другу** — то, из-за чего абзац «залипает»: «рассказать рассказ», «моря — морем», «буквально… буквально».

Статус: **шаг 2 из 4** — ядро и подсветка в редакторе работают. Панели со списком находок пока нет.

## Установка

**Из релиза.** Скачать из последнего релиза `main.js`, `manifest.json` и `styles.css` и положить в `<хранилище>/.obsidian/plugins/fresh-eye/`. Затем в Obsidian: **Настройки → Сторонние плагины → включить «Свежий взгляд»**.

**Вручную при разработке.** Скопировать те же три файла из корня репозитория после `npm run build`.

Для пробы есть готовое хранилище `dev-vault`: откройте папку `dev-vault` как хранилище (Obsidian → «Открыть другое хранилище») — в нём уже лежит заметка «Проверка» с намеренными повторами.

## Похожие плагины

В каталоге Obsidian есть `repeated-words` — подсветка повторов для английского и испанского, по точному совпадению слова. «Свежий взгляд» отличается русским языком и метрикой созвучия: он ловит не только одинаковые слова, но и однокоренные созвучия вроде «рассказал — рассказ».

## Что работает

- Подсветка слов, участвующих в подозрительных парах, прямо в Live Preview.
- Повторы группируются: четыре «квадрат» подряд — одна группа, а не шесть отдельных подсветок.
- Тултип при наведении: что именно не так и насколько (««квадрат» — 4 раза подряд · 1165»).
- Счётчик находок в статус-баре.
- Команды: «Проверить заметку» и «Включить или выключить проверку при наборе».
- Настройки: порог чувствительности (по умолчанию 800), размер окна, исключение имён собственных, проверка при наборе.
- Код, ссылки, теги, math и frontmatter не проверяются.

## Как это работает

1. Текст разбирается на русские слова; всё остальное считается разделителем.
2. Каждое слово сравнивается с 20 предыдущими.
3. Похожесть считается по таблице частичного сходства русских букв, весам информативности букв и динамическому программированию по совпадающим диагоналям.
4. Похожесть умножается на гауссово затухание по расстоянию: пробел весит 1, запятая — 2, точка — 4, граница абзаца — 8.
5. Пары с «плохостью» ниже порога отбрасываются; легитимные сочетания («друг друга», «так как») отсекаются словарём исключений.

## Порог

На двух рассказах (1477 и 2731 слово) при разных порогах:

| Порог | Рассказ 1 | Рассказ 2 | Из них буквальный повтор слова |
|-------|-----------|-----------|-------------------------------|
| 400   | 109       | 223       | ~29%                          |
| 600   | 42        | 99        | ~50%                          |
| **800** | **21**  | **48**    | **63–76%**                    |
| 1000  | 10        | 21        | 80–95%                        |

800 — режим по умолчанию. 600 — «тщательная вычитка»: вдвое больше находок, среди них есть спорные.

Известное ограничение: правило ловит **созвучие**, а не общий корень. «Старый старик» (674) и «моря — морем» (603) на пороге 800 не подсвечиваются. На 600 — ловятся. Настоящий детектор однокоренных слов требует морфологии и пока не сделан.

```bash
node tools/report.mjs путь/к/тексту.txt --threshold=800 --limit=20
node tools/stats.mjs samples/рассказ1.txt samples/рассказ2.txt
```

## Устройство

```
src/core/         алгоритм и кластеризация, без импортов из obsidian
src/plugin/       плагин: main, editor, prose, markdown, settings
tools/            генераторы таблиц/фикстур, CLI и отчёты
vendor-src/       исходники Go-версии, из которых извлечены таблицы и golden-тесты
test/             21 тест, включая сквозной тест против Go-версии
dev-vault/        хранилище для проверки плагина вручную
```

`src/core/tables.ts` генерируется из `vendor-src/context.go` командой `npm run tables`.
